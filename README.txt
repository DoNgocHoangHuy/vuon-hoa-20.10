VƯỜN HOA YÊU THƯƠNG — 20/10

Cách mở:
1. Giải nén file ZIP.
2. Mở index.html bằng Chrome, Edge hoặc trình duyệt bất kỳ.
3. Không cần cài đặt hay kết nối Internet.

Có sẵn:
- Vườn hoa hoạt hình với hoa nhiều màu.
- Hoa/cây đung đưa nhẹ nhàng.
- Mây trôi, mặt trời phát sáng, đom đóm.
- Cánh hoa và trái tim tự động rơi.
- Nút “Thả phép màu yêu thương” tạo hiệu ứng bùng nở.
- Tối ưu cho màn hình điện thoại và máy tính.
